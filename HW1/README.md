# CS 6220 Homework 1: Iris Classification

This project trains a logistic regression model to predict Iris flower
classes from four flower measurements.

## Files

- `homework_1.ipynb` — code, explanations, and results
- `iris.data` — Iris dataset downloaded from the UCI repository
- `requirements.txt` — required Python packages

## How to run

1. Install Python 3 and VS Code with the Python and Jupyter extensions.
2. Open this folder in VS Code.
3. Open a terminal in this folder and run:
 
   python3 -m pip install -r requirements.txt
